## 🛠️ Enfoque técnico

- **Frontend & UI Responsive:** Interfaces adaptables a cualquier resolución (desde relojes 240px hasta pantallas 4K), multi-idioma y enfocadas en experiencia de usuario.
- **Backend & APIs:** Desarrollo de servicios REST con Node.js, Express y TypeScript, manejo de bases de datos SQL/Turso, colas de mensajes y webhooks.
- **Aplicaciones de Escritorio:** Software multiplataforma con Electron orientado a entornos *offline-first*, reportes automatizados y copias de seguridad locales.
- **Integración de IA:** Implementación práctica de LLMs (Claude API) para procesamiento de lenguaje natural, generación de contenido estructurado y atención automatizada.
- **Seguridad y Calidad:** Autenticación con JWT y `scrypt`, verificación de firmas HMAC (`X-Hub-Signature-256`) y pruebas automatizadas con Vitest.

### 🧾 [Factura·IA](https://github.com/Jsonserrano/factura-ia) — Facturador de venta con IA
Aplicación que convierte texto o voz en facturas estructuradas con cálculo de impuestos, descuentos, **CUFE SHA-384**, **QR**, **XML UBL 2.1** y exportación a PDF. Incluye gestión de cartera, API con autenticación (`JWT`, `scrypt`), base de datos en la nube y **69 pruebas automatizadas**.  
`TypeScript` `Express` `Turso` `Vitest` · **[Ver demo](https://jsonserrano.github.io/factura-ia/)**

Aplicación corporativa de rutinas guiadas con cronómetro y notificaciones. Integra **Claude API** para generar ejercicios personalizados (con motor local *fallback* sin conexión), reportes en Excel protegidos con contraseña, copias de seguridad y soporte bilingüe (ES/EN).  
`Electron` `JavaScript` `ExcelJS` `Claude API`
