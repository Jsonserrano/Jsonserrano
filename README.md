### 🧾 [Factura·IA](https://github.com/Jsonserrano/factura-ia) — Facturador de venta para Colombia
Escribes o dictas la venta (*"3 camisetas a 45 mil, 2 gorras con 10 % de descuento"*) y la IA arma la factura: impuestos, descuentos, **CUFE SHA-384**, **QR**, **XML UBL 2.1**, PDF y envío por WhatsApp o correo. Historial con lo facturado y lo pendiente por cobrar. API con usuarios (JWT, scrypt), base de datos en la nube y **69 pruebas automáticas**.
`TypeScript` `Express` `Turso` `Vitest` · **[Ver demo](https://jsonserrano.github.io/factura-ia/)**

### 🌟 [Pausas Activas](https://github.com/Jsonserrano/pausas-activas) — App de escritorio para Seguridad y Salud en el Trabajo
Rutina de pausas guiada paso a paso con cronómetro. El botón **"Nuevo ejercicio IA"** crea ejercicios a la medida (zona del cuerpo, duración, intensidad y un pedido especial) con **Claude**, o con un generador propio cuando no hay internet. También tiene recordatorios con notificaciones, reporte SST en Excel protegido con contraseña, copias de seguridad y limpieza automática de caché. En español e inglés.
`Electron` `JavaScript` `ExcelJS` `API de Claude`

### 🤖 Connexa SAS — Bot de WhatsApp con IA *(en desarrollo)*
- **Editor visual de flujos** (arrastrar y soltar, fondo oscuro): inicio, mensajes con imagen, botones, listas, preguntas, condiciones, paso a un asesor y agente de IA. Tiene simulador para probar el flujo y exporta a JSON.
- **Servidor del bot** en TypeScript conectado a la **API oficial de WhatsApp Cloud (Meta)**: verifica la firma `X-Hub-Signature-256`, evita mensajes duplicados, mantiene una cola por cliente, sube imágenes y usa **Claude** para responder dentro del tema del negocio o pasar la conversación a una persona.
